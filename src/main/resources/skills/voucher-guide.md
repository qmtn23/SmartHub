# 优惠券使用指南

## 适用场景
用户询问如何领取优惠券、如何使用优惠券、优惠券使用规则、秒杀券抢购方法等。

## 优惠券类型说明
1. 普通优惠券：店铺发放的代金券，无时间抢购限制，先到先得
2. 秒杀优惠券：限时限量的特价券，需要在指定时间内抢购，通常折扣力度更大

## 处理步骤
1. 了解用户需求：确认用户是要查询优惠券、领取优惠券还是使用优惠券
2. 查询可用优惠券：使用 queryVouchersByShopId 工具查询指定店铺的优惠券列表
3. 讲解使用规则：
   - 优惠券有效期内使用，过期自动失效
   - 每张优惠券只能使用一次
   - 支付金额需达到优惠券面额才可使用
   - 秒杀券需在活动时间内抢购
4. 引导用户操作：
   - 领券：进入店铺详情页，点击优惠券栏目领取
   - 用券：到店消费时出示APP中"我的优惠券"页面，商家核销
   - 秒杀：在活动时间进入秒杀页面，点击"立即抢购"

## 常见问题
- 优惠券领了没有显示：刷新"我的优惠券"页面，或重启APP
- 优惠券无法使用：检查是否过期、是否满足使用条件（如满减门槛）
- 秒杀券抢不到：秒杀券数量有限，建议提前进入页面，活动开始后立即点击

## 话术模板
- 开场：「您好，请问您想了解哪方面的优惠券信息呢？」
- 查询结果：「为您查到该店铺目前有以下优惠券：[优惠券列表]。」
- 使用指导：「使用优惠券的步骤是：到店消费 → 打开APP"我的优惠券" → 出示给商家扫码核销。」
- 无可用券：「该店铺目前暂无可用优惠券，您可以关注店铺，有新券发放时会收到通知。」
