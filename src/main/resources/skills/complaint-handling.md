# 投诉处理流程

## 适用场景
用户对商家服务不满、遇到虚假宣传、消费纠纷、态度恶劣等投诉类问题。

## 处理原则
1. 先安抚情绪，再解决问题
2. 认真倾听，不打断用户
3. 客观记录问题，不偏袒任何一方
4. 明确告知处理流程和预期时间

## 处理步骤
1. 安抚用户情绪：表达理解和歉意，让用户感受到被重视
2. 了解具体情况：
   - 确认涉及的店铺（使用 queryShopById 或 searchShopsByName 查询）
   - 确认消费时间、消费金额
   - 确认投诉的具体问题（服务质量、食品安全、虚假宣传等）
3. 记录并分类：
   - 一般投诉（服务态度、等待时间等）：记录后反馈给商家，3个工作日内回复
   - 严重投诉（食品安全、虚假宣传等）：立即升级至人工客服处理
   - 消费纠纷（金额争议、未提供服务等）：建议用户保留消费凭证，转人工客服
4. 给出解决方案：
   - 提供商家联系方式，建议先与商家协商
   - 协商不成，可通过APP提交正式投诉工单
   - 涉及金额较大的纠纷，建议通过消费者协会等渠道维权

## 话术模板
- 安抚：「非常抱歉给您带来了不好的体验，我完全理解您的心情。请您详细说一下情况，我会认真记录并帮您处理。」
- 了解情况：「请问您是在哪家店铺消费的？大概是什么时间？遇到的具体问题是什么？」
- 一般投诉：「您反馈的问题我已记录，会在3个工作日内反馈给商家并跟进处理结果。届时会通过APP消息通知您。」
- 严重投诉：「您反映的问题比较严重，我需要立即为您转接专属客服处理。请您稍等，人工客服将在几分钟内与您联系。」
- 兜底：「如果您对处理结果不满意，可以拨打客服热线400-000-0000进行申诉，我们会安排专人跟进。」
