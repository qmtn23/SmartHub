# 投诉处理流程

## 适用场景
用户对商家服务不满、遇到虚假宣传、消费纠纷、态度恶劣等投诉类问题。

## 处理原则
1. 先安抚情绪，再解决问题
2. 认真倾听，不打断用户
3. 客观记录问题，不偏袒任何一方
4. 明确告知处理流程和预期时间

## 处理步骤
1. 安抚用户情绪：表达理解和歉意，让用户感受到被重视
2. 了解具体情况：
   - 确认涉及的店铺（使用 queryShopById 或 searchShopsByName 查询）
   - 确认消费时间、消费金额
   - 确认投诉的具体问题（服务质量、食品安全、虚假宣传等）
3. 判断并分类：
   - 一般投诉（服务态度、等待时间等）：建议转人工客服确认后续处理方式
   - 严重投诉（食品安全、虚假宣传等）：立即引导用户使用转人工入口
   - 消费纠纷（金额争议、未提供服务等）：建议用户保留消费凭证，并使用转人工入口
4. 给出解决方案：
   - 提供商家联系方式，建议先与商家协商
   - 协商不成，可转人工客服进一步处理
   - 涉及金额较大的纠纷，建议通过消费者协会等渠道维权

## 话术模板
- 安抚：「非常抱歉给您带来了不好的体验，我完全理解您的心情。请您详细说一下情况，我会认真记录并帮您处理。」
- 了解情况：「请问您是在哪家店铺消费的？大概是什么时间？遇到的具体问题是什么？」
- 一般投诉：「我已了解您反馈的情况，这类问题建议由人工客服进一步确认。请使用当前页面的转人工入口。」
- 严重投诉：「您反映的问题比较严重，需要人工客服进一步处理。请使用当前页面的转人工入口；进入等待队列后，您可以继续补充相关凭证和信息。」
- 兜底：「如果您对处理结果不满意，可以拨打客服热线400-000-0000进行申诉，我们会安排专人跟进。」
