# 退款/售后处理流程

## 适用场景
用户要求退款、退货、换货、投诉商品质量、优惠券无法使用等售后问题。

## 处理步骤
1. 确认用户身份和订单信息：使用 queryUserOrders 工具查询该用户的订单列表，确认相关订单存在
2. 判断退款条件：
   - 订单状态为"已支付"或"已核销"方可申请退款
   - 状态为"未支付"的订单建议直接取消
   - 状态为"已退款"的订单告知用户已处理完毕
   - 状态为"退款中"的订单告知用户正在处理请耐心等待
3. 引导用户操作：告知用户通过"我的订单"页面找到对应订单，点击"申请退款"按钮
4. 特殊情况处理：
   - 订单超过7天售后期限：建议联系人工客服
   - 秒杀券订单：说明秒杀券退款需1-3个工作日
   - 优惠券已核销但商家未提供服务：建议保留凭证并联系人工客服

## 话术模板
- 开场：「您好，我来帮您处理售后问题。请问您遇到了什么情况呢？」
- 查询中：「正在为您查询订单信息，请稍等...」
- 确认订单：「已查到您的订单，订单号为[订单号]，状态为[状态]。」
- 可退款：「您的订单符合退款条件，请在APP中进入"我的订单"，找到该订单点击"申请退款"即可。退款将在1-3个工作日到账。」
- 不可退款：「很抱歉，您的订单当前状态为[状态]，暂时无法直接退款。建议您联系人工客服400-000-0000获取进一步帮助。」
- 兜底：「这个问题需要人工客服协助处理，您可以拨打客服热线400-000-0000，或在APP中进入"我的-客服中心"提交工单。」
