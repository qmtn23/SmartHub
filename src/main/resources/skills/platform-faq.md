# 平台常见问题FAQ

## 适用场景
用户询问平台基本功能使用、账号问题、积分规则、签到功能等通用性问题。

## 账号相关

### 注册与登录
- 注册方式：使用手机号注册，输入手机号后获取验证码即可完成注册
- 登录方式：手机号+验证码登录，验证码有效期为2分钟
- 忘记密码：平台采用验证码登录，无需密码，直接用手机号获取新验证码即可
- 换绑手机：需联系人工客服400-000-0000进行手机号变更

### 个人信息
- 修改昵称/头像：进入"我的" → 点击头像区域 → 编辑个人资料
- 隐私设置：可以在"我的" → "设置"中调整个人主页可见范围

## 探店笔记相关

### 发布笔记
- 发布入口：首页底部"+"按钮 → 选择图片 → 编辑文字 → 关联店铺 → 发布
- 图片要求：支持最多9张图片，建议使用高清原图
- 内容规范：不得包含虚假信息、广告推广、违法违规内容

### 互动功能
- 点赞：点击笔记下方爱心图标
- 评论：点击评论图标，输入评论内容
- 关注：点击笔记作者头像旁的"关注"按钮

## 优惠券与消费

### 优惠券使用
- 领取：进入店铺详情页 → 优惠券栏目 → 点击领取
- 使用：到店消费 → 打开"我的优惠券" → 出示给商家核销
- 有效期：每张券有独立有效期，过期自动失效，不支持续期

### 秒杀活动
- 入口：首页"秒杀专区"或店铺详情页的秒杀券
- 规则：限时限量，每人限购一张，需在活动时间内操作
- 支付：抢购成功后需在规定时间内完成支付，超时自动取消

## 其他功能

### 签到
- 签到入口：首页顶部"签到"按钮或"我的"页面
- 签到奖励：每日签到可获得积分，连续签到有额外奖励
- 积分用途：积分可在积分商城兑换优惠券或小礼品

### 关注与推荐
- 关注店铺：店铺详情页点击"关注"，可收到店铺动态和优惠通知
- 关注用户：在用户主页点击"关注"，可在"关注"页面查看其新笔记
- 推荐机制：首页推荐基于用户兴趣和热度，关注的人和店铺优先展示

## 话术模板
- 通用回答：「关于您的问题，[具体解答]。如果还有其他疑问，随时问我哦！」
- 功能引导：「您可以通过以下步骤操作：[步骤说明]。」
- 无法解答：「这个问题我暂时无法直接解答，建议您联系人工客服400-000-0000获取更准确的帮助。」
